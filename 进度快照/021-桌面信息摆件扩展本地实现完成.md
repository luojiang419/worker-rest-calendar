# 021 · 桌面信息摆件扩展本地实现完成

## 当前目标

在既有单窗口桌面摆件中增加倒数日、待办清单、月相、系统状态和天气，并将数字时钟升级为拟物化圆形模拟时钟；完成本地验证但不提交、不推送、不发布。

## 已完成内容

1. `DesktopWidgetType` 从 4 种扩展到 9 种，设置页与 Windows 原生菜单均可切换。
2. 数据库从 v8 升级到 v9，新增倒数日标题/日期、待办 JSON、天气城市字段；v1/v2/v5 迁移测试通过。
3. 倒数日保存一个主目标；待办最多 8 项，支持添加、勾选和删除；数据进入备份导入导出。
4. 月相使用纯 Dart 朔望月算法计算月龄、照明比例和八种中文月相，并使用 `CustomPainter` 自绘月盘。
5. Windows 新增系统状态 MethodChannel，原生读取 CPU、内存和电池，不读取进程列表或用户文件。
6. 天气使用 Open-Meteo 城市解析和当前天气接口，无 API 密钥，30 分钟内存缓存，网络失败时回退已有缓存；默认城市为北京且设置页可修改。
7. 时钟改为拟物圆形表盘，包含时、分、秒针，同时保留数字时间、日期、排班状态和下次休息摘要。
8. 五种视觉风格、浅/暗主题、小中大尺寸与 130% 字体回归已覆盖。
9. Windows CMake 增加 `/utf-8`，修复中文系统下 UTF-8 C++ 源码被代码页 936 错误解析的问题。
10. 隐私说明已披露 Open-Meteo 城市/坐标请求和数据范围。

## 关键代码前后对比

### 摆件路由

修改前：非排班摆件只有时钟、记事本和专注计时；时钟依赖排班快照，其余两种独立加载。

修改后：增加倒数日、待办、月相、系统状态和天气分支；只有排班与时钟订阅排班数据，信息摆件各自读取本地设置或 adapter，互不阻塞。

### 时钟

修改前：以大号数字显示 `HH:mm` 和秒数。

修改后：使用径向材质、主题阴影、60 个刻度与三根表针绘制圆形拟物表盘，并按尺寸重排数字时间和排班摘要。

### 持久化

修改前：数据库 v8 仅保存摆件类型和快速便笺。

修改后：数据库 v9 额外保存倒数日标题/日期、最多 8 项待办 JSON 和天气城市；旧数据库与缺少新字段的旧备份使用兼容默认值。

### 平台与天气

修改前：没有系统状态或天气数据源。

修改后：`SystemStatusService` 通过 Windows MethodChannel 读取受限指标；`WeatherService` 通过可替换 transport 调用 Open-Meteo，并在请求失败时使用缓存。
