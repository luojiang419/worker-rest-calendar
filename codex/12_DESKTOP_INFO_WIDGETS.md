# Phase 12 · 桌面信息摆件扩展

## 目标

在既有单窗口桌面摆件架构中增加倒数日、待办清单、月相、系统状态和天气摆件，并将时钟升级为拟物化圆形模拟时钟。所有摆件继续共享窗口位置、尺寸、透明度、置顶、锁定、主题与原生菜单能力。

## 范围约定

- 继续只使用一个无边框 Flutter 窗口，不创建额外进程或 Flutter 引擎。
- 倒数日保存一个主目标；待办最多保存 8 项，支持添加、勾选与删除。
- 月相由本地纯 Dart 算法计算，不引入 GPL 依赖或网络请求。
- 系统状态通过平台 adapter 读取；Windows 首批显示 CPU、内存和电池，未知能力显示“不可用”。
- 天气使用 Open-Meteo，无 API 密钥；默认城市为北京，允许在设置页修改，并提供缓存与失败降级。
- 开源项目仅作为布局和交互参考，不直接复制来源不清或许可证不兼容的代码。

## 模块

1. 类型与持久化：新增五种 `DesktopWidgetType`，数据库升级，备份向后兼容。
2. 领域逻辑：倒数日、待办、月相、天气码和系统状态模型。
3. 数据适配：Open-Meteo 天气服务与 Windows 系统状态平台通道。
4. 卡片 UI：五种新摆件与拟物圆形时钟，全部读取设计令牌。
5. 入口与交互：设置页、原生菜单、摆件路由和本地保存。

## 验收标准

- 九种摆件切换立即生效，重启后保持最后选择。
- 倒数日、待办和天气城市可编辑并持久化，备份导入导出可恢复。
- 月相算法覆盖新月、上弦、满月、下弦及跨日边界。
- 天气无网络时显示缓存；无缓存时显示可重试状态，不阻塞其他摆件。
- Windows 系统指标定时刷新，平台不支持时安全降级。
- 圆形时钟显示时、分、秒针和排班摘要，前台恢复后校正时间。
- 五种视觉风格、浅色与暗黑模式、小中大尺寸、130% 字体无核心溢出。
- 格式化、静态分析、单元测试、Widget 测试和现有集成测试通过后才更新进度。
